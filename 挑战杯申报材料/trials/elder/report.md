### 2.1 开关在哪

- 位置：**顶部栏右上角**，紧挨搜索图标，胶囊按钮，文案"长辈版"。
- 尺寸：**80 × 32 px**，距屏幕右边缘约 31 px（搜索钮占掉右侧 33 px）。
- 对比 `trials/elder/a1_home_before_elder.png`：一眼能看见，但 **32 px 高低于 44 px 的触控建议值**（我这种手指粗、还有点抖的人按下去容易偏）。
- 打开后按钮文字变"标准字"、底色变深绿（`a3_home_after_elder.png`），状态可辨。

### 2.3 发现的真 bug（值得单独修）

`App.vue` 的 `<style scoped>` 里，以 `:global(...)` 开头再拼后代选择器的写法，在 Vue SFC 编译后**后代选择器被整体丢弃**。Vite dev 下抓到的编译产物原文：

```
输入:  :global(:root:is([data-fontsize="large"], [data-fontsize="xlarge"])) .mtab-label { font-size: 13px; ... }
产物:  :root:is([data-fontsize="large"], [data-fontsize="xlarge"]) { font-size: 13px; font-weight: 600; }
```

`.mtab-label`、`.elder-btn`、`.top-back`、`.mobile-tabbar`、`.mtab-item.active .mtab-icon` 全部消失，规则退化成给 `<html>` 设字号（对布局无实际影响）。后果：

1. 长辈版下底部导航标签不放大（仍 11.5 px）；
2. 顶栏"长辈版"按钮和子页"返回"按钮不放大（仍 32 px / 35 px 高，低于 44 px）；
3. **暗色模式下底部导航栏背景不变**（实测切 `van-theme-dark` 后 `.mobile-tabbar` 背景仍是 `rgba(253,250,241,0.96)` 米白，夜里会晃眼）。

改法建议（未改动产品代码）：把后代一起塞进 `:global()`，即 `:global(:root:is([data-fontsize="large"]) .mtab-label) {...}`；或把这几条移到非 scoped 的 `<style>` 块。

## 五、安全提示可发现性（高血压用户视角）

**结论：能找到，但前提是我先做对了两件事，而且第一件事没人告诉我。**

1. **不知道要去设"人群档案"。** 安全提示条是**条件渲染**的——不设人群模式时，详情页顶部根本不出现任何高血压相关提示（`SafetyBanner` 组件 `v-if` 为空即不渲染）。我第一次看"疏肝解郁安神茶"时（`a6_detail_top.png`），页面上**一个"高血压"字样都没有**，只有"经量多的女性经期暂停；孕妇不能喝"。我一个高血压患者看完，**无法判断这茶对我安不安全**。
2. **设了之后效果很好。** 在方子库点"高血压"标签后，列表卡片直接长出"含 甘草，高血压人群请咨询医生后使用"的提示行，被拦的卡片还有整卡变红的样式；再点进详情，**首屏最顶部就是黄色警示条**"高血压人群注意 / 甘草：含 甘草，高血压人群请咨询医生后使用"（`a9_detail_safety_banner.png`、`b_detail_with_banner_first_screen.png`）。位置在距页顶 64 px 处，**一眼就看到**，字号长辈版下 16.5 px。这个设计是对的。
3. **但"注意与禁忌"框在 2139 px 处（约 2.29 屏）**，得滑两屏多才看到（`a6c_detail_suitable.png`）。长辈版下 15.5 px、红字红底，**找到了就不难读**，问题是滑到那儿之前我已经打算走了。
4. **文案重复**："甘草：含 甘草，高血压人群请咨询医生后使用"——"甘草"说了两遍，像程序拼串没去重，读着别扭。
5. 全局免责声明"本平台内容为健康参考信息…"在每页底部，长辈版下 14 px，规范。

**一句话**：安全机制本身做得挺扎实（分级 block/warn、列表+详情双处提示），**但入口是"默认关闭"的**，对不会设档案的老人等于不存在。建议首次进入时主动问一句"您有高血压/糖尿病吗"。

## 六、其他实测问题

1. **搜索完全搜不到疾病词。** 实测 6 个词（`measurements.search_keywords`）：
   - 搜不到：`高血压`、`睡不着`、`降压` → 都返回"没有找到「XX」相关内容"（`a10_search_hypertension.png`）
   - 搜得到：`助眠`(方子)、`安神`(方子+药材+成分)、`失眠`(方子，仅 1 条)

   我作为高血压患者最自然的输入就是"高血压"和"降压"，结果一片空白。**这是最伤的一次体验**——我会以为这平台没有我能喝的东西。建议做同义词映射：高血压→平肝/降压/决明子/菊花，睡不着→助眠/安神/失眠。
2. **搜索框在窄屏收成 33 × 33 px 的圆形图标**（`x=385`），比 44 px 建议值小一圈，我第一眼没认出那是搜索。
3. **慢病安全滤镜的标签只有 32 px 高**（"高血压"67 × 32 px），低于 44 px，点起来要瞄准。
4. **老花眼最怕的小字仍在**：场景卡说明 10.5 px、场景卡计数 10.5 px，长辈版下**一个都没放大**（`e1_elder_scene_grid.png` 可见"咽干用嗓多"仍很小）。
5. **方子标题在长辈版下反而缩小 1 px**（22 → 21 px）。虽然视觉上无感，但逻辑上不该出现。
6. **"今日打卡"未登录会直接跳登录页**（实测跳 `/login?redirect=/recipes/15`）。对我是打断，但页面有"暂不登录，返回刚才页面 →"的软出口，可以接受。
7. 控制台有 2 条 `pageerror: Cannot read properties of undefined (reading 'length')`，出现在首轮运行的成分页附近；补测复现时未再出现（`pageerrors_after_nav` / `pageerrors_home` / `pageerrors_recipes` 均为空），未定位到稳定复现路径，**记录备查**。

## 七、一句话总评

**作为 62 岁、眼睛花、有高血压的用户：字放大了一点、正文读得懂了，方子详情页的大白话讲得很贴心，但我不敢自己用。**

原因很具体：我最想问的"我这血压能不能喝这杯茶"，在没设档案时**页面上一个字都不提**；我自然会去搜"高血压"，**搜出来是空的**；底部导航那 6 个字在最该大的时候没变大，而我全靠它认路。**如果女儿帮我把"高血压"滤镜点开、再教我在方子库里按场景翻**，我敢用；**让我自己从首页摸进去，我会在第一屏就放弃，回去问人。**
